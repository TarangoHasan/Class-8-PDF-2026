# NCTB Class 8 Textbooks & Split Chapters (2026 Academic Year)

This repository contains the complete collection of systematically split, verified, and chapter-wise partitioned PDF files for **NCTB (National Curriculum and Textbook Board, Bangladesh)** Class 8 textbooks (2026 academic year).

Each textbook has been reviewed page-by-page, preserving preface metadata (chapter-00-preface.pdf) and partitioning every individual chapter into self-contained files (chapter-01.pdf onwards) suitable for human study, AI document ingestion, and RAG architectures.

> **Note on Original (Raw) Full PDFs**:
> The complete un-split original PDFs are hosted via Cloudflare block storage / CDN, keeping this repository lean and focused on modular chapter PDFs.
